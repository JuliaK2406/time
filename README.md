# Webinar timer: часы и таймер для вебинаров Юлии

Две лёгкие страницы для демонстрации экрана в Zoom, в стиле Mosaic of Life.
Только HTML, CSS и JS: без сборки, зависимостей, аналитики, cookies и сторонних запросов.

- `index.html`: часы. Время Амстердама (`Europe/Amsterdam`) на любом компьютере,
  подпись CET зимой и CEST летом, дата.
- `timer.html`: обратный отсчёт с мозаикой 8 × 5, которая собирается к концу.

## Как пользоваться таймером

- Длительность: кнопки 1, 2, 3, 5, 10, 15 минут или своё число от 1 до 120 в поле.
- Ссылка с готовой длительностью: `timer.html?min=5`.
- Клавиши: пробел старт и пауза, `R` сброс, `F` полный экран (выход `F` или `Esc`).
  Клавиши работают и на русской раскладке.
- В полном экране видны только цифры и мозаика.
- После `Time’s up` пробел ничего не делает, чтобы таймер не запустился случайно.
  Новый круг: `R` или кнопка `Reset`.

## Файлы

- `styles.css`: общие стили. Блок токенов скопирован целиком из
  `mosaic-snapshot/src/styles/tokens.css`.
- `clock.js`, `timer.js`: логика экранов. Таймер считает от момента окончания,
  поэтому не отстаёт, когда вкладка в фоне.
- `fonts/`: Lora и Inter (SIL Open Font License, тексты лицензий рядом).
- `robots.txt` и `<meta name="robots" content="noindex">`: страница закрыта от поисковиков.

## Публикация

Репозиторий `JuliaK2406/time`, адрес `https://juliak2406.github.io/time/`.
GitHub Pages в режиме GitHub Actions: `.github/workflows/deploy.yml` выкладывает корень
репозитория как есть, без сборки. Пуш в `main` обновляет страницу примерно за минуту.

## Локальный просмотр

```bash
python3 -m http.server 8765
```

Затем открыть `http://localhost:8765/`.
